# Changelog

Список основных изменений коммерческого Django-проекта для бронирования домов.  
Исходный код не публикуется, так как проект используется в реальном production-сценарии.

## Основные этапы разработки

### Система бронирования и календарей

- Реализована система бронирования домов.
- Добавлен выбор диапазона дат через календарь Flatpickr.
- Реализованы календари занятости и доступности.
- Добавлено отображение прошедших дат в календарях.
- Настроен срок удержания брони.
- Доработана логика бронирования граничных дат:
  - день выезда может быть доступен для следующего заезда;
  - учтены короткие свободные промежутки между бронированиями;
  - добавлена защита от некорректного выбора дат;
  - добавлены исключения из правила минимального срока проживания в пик сезона.

### Цены, скидки и акции

- Реализованы сезонные цены в расчёте бронирования.
- Добавлена модель скидок.
- Реализованы два типа скидок:
  - процентная скидка;
  - фиксированная скидка в рублях за ночь.
- Добавлен единый расчёт скидки в рублях:
  - в календарях;
  - в форме бронирования;
  - в уведомлениях.
- Добавлено отображение скидочных дней в календарях.
- Добавлена золотая подсветка скидок и акций.
- В общем календаре реализовано отображение минимальной цены среди свободных домов.
- Реализована страница акций:
  - модель Promotion;
  - фотографии акций;
  - карточки акций;
  - даты действия акций;
  - пункт меню «Акции».
- Добавлен баннер акций с редактируемым текстом кнопки.

### Административная часть

- Настроена административная панель Django Admin.
- Добавлено управление контентом сайта через админку.
- Реализовано управление скидками и акциями через административную часть.
- Добавлена возможность редактирования отдельных текстовых элементов сайта из админки.
- Добавлена подпись разработчика и копирайт, управляемые через админку.

### iCal-синхронизация

- Реализована синхронизация календарей через iCal.
- Добавлена логика учёта занятости домов на основе календарных данных.
- Синхронизация используется для корректного отображения доступности и бронирований.

### Страницы, галереи и интерфейс

- Реализованы страницы домов с описанием, фотографиями и условиями проживания.
- Добавлены галереи изображений.
- Добавлена поддержка видео в галерее дома.
- Реализован lightbox для просмотра фотографий.
- Добавлены баннеры внутренних страниц.
- Добавлена плавающая кнопка контактов.
- Добавлена кнопка «Наверх».
- Добавлена кнопка перехода в 2ГИС.
- Переработан футер:
  - фото-фон;
  - навигация;
  - копирайт;
  - подпись разработчика;
  - тени текста;
  - скрытие/отображение отдельных блоков.
- Выполнен рефакторинг CSS с использованием переменных.
- Выполнена мобильная адаптация интерфейса.

### SEO и технические доработки

- Добавлены уникальные meta description для страниц.
- Добавлен favicon.
- Добавлена OG-картинка для предпросмотра ссылок.
- Обновлены версии CSS-файлов для корректного обновления стилей у пользователей.
- Выполнены технические исправления шаблонов и структуры страниц.
