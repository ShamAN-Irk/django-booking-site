# Deployment notes

## Общий подход

Проект был развернут на Linux VPS с использованием Django, PostgreSQL, Gunicorn и Nginx.

Целью было получить рабочее web-приложение, доступное по домену через HTTPS.

## Основные этапы

1. Подготовка VPS.
2. Установка Python, PostgreSQL, Nginx, Git и зависимостей.
3. Клонирование проекта на сервер.
4. Создание виртуального окружения Python.
5. Установка зависимостей проекта.
6. Настройка переменных окружения.
7. Настройка PostgreSQL.
8. Выполнение миграций Django.
9. Сбор статических файлов.
10. Настройка Gunicorn.
11. Настройка Nginx.
12. Подключение домена.
13. Настройка HTTPS.
14. Проверка работы сайта.

## Что было изучено на практике

- работа с Linux VPS;
- настройка Python-проекта на сервере;
- работа с виртуальным окружением;
- настройка PostgreSQL;
- настройка Gunicorn;
- настройка Nginx;
- работа со статическими файлами Django;
- подключение домена;
- базовая диагностика ошибок при deployment;
- проверка логов и исправление проблем конфигурации.

## Безопасность

В публичный репозиторий не выкладываются:

- исходный код рабочего проекта;
- `.env`;
- секретный ключ Django;
- пароли;
- данные пользователей;
- настройки реального сервера;
- приватные конфигурационные файлы.
