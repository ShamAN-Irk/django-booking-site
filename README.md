# Django booking website — production case study

Публичное описание коммерческого production-проекта: сайта для презентации домов, управления доступностью и обработки заявок на бронирование.

Исходный код проекта не публикуется, так как проект используется в реальном коммерческом сценарии, связан с рабочим доменом, серверной инфраструктурой, приватной конфигурацией, бизнес-логикой и пользовательскими данными. В репозитории представлено описание проекта, архитектуры, стека и выполненных задач.

## О проекте

Проект представляет собой сайт для объекта размещения: публикация информации о домах, фотографий, условий проживания, акций, календарей доступности и заявок на бронирование.

Сайт разрабатывался не как учебный пример, а как рабочий production-проект для реальных пользователей. В процессе разработки учитывались реальные требования владельцев проекта, сценарии бронирования, сезонные цены, скидки, акции, календарная доступность и административное управление контентом.

## Почему код не опубликован

Код проекта не публикуется в открытый доступ, потому что проект является рабочим коммерческим сайтом и не принадлежит мне как личный pet-project.

Публичная публикация исходного кода могла бы раскрыть:

- внутреннюю бизнес-логику;
- структуру рабочего проекта;
- настройки окружения;
- детали серверной конфигурации;
- особенности бронирования;
- приватные данные и пользовательские сценарии.

Поэтому данный репозиторий используется как case study: описание проекта, архитектуры, применённого стека и выполненных задач без раскрытия приватного кода.
